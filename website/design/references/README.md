# Supplied reference image archive

This directory contains exact copies of the eight images supplied in the Cinch site design conversation. [manifest.json](manifest.json) records their original attachment names, dimensions, sizes, descriptions, and SHA-256 hashes. The files were copied without visual edits or resizing.

Start with [the inspiration atlas](../inspiration-atlas.md) for the source links, the user's feedback, and the qualities to carry into future work. [The design handbook](../design-handbook.md) explains how those qualities are applied in the site.

These are study references outside `public/`. Keeping them here does not make them production assets or establish rights to third-party artwork. Preserve watermarks and provenance. Use original explanatory diagrams and the selected brand assets when building pages.

The existing [video overview contact sheet](../../screenshots/references/silo-contact-sheet.jpg) and [detail sheet](../../screenshots/references/silo-details.jpg) preserve the earlier video study. The full film remains an external reference linked from the atlas.

Raw byte input stays arbitrary and lossless; numeric encoding still accepts `I32`, including explicit replacement for invalid numbers. The facade exposes fresh rune encoding/append, checked atomic encoding into an existing buffer, raw decoding/count/validation, bounded span queries, repair, and exact step metadata.

First and last text observations return the opaque `Utf8Step`. Empty text has U+FFFD, width zero, and `Utf8End`; nonempty text has the exact scalar/width and `Utf8Valid`. The private adapter uses safe scalar/end factories rather than exposing the step constructor. Validity follows the String invariant; a complete first scalar is exactly nonemptiness. The facade never copies or exposes the String backing.

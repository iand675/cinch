Pending gates and limits:

- Production prelude/distribution availability: Root integrated only experiments/uuid-candidate-v1 plus SDK-free tests; user-facing Data.Uuid/Effect.Uuid are not promoted.
- Review intentional adaptations: total checked-parser witness instead of panic, immutable receiver replacement, and explicit per-generator V7 state instead of implicit process-global state.
- Full historical Native pure matrix remains incomplete; current Native IO/MVar family qualification is separate and unclaimed.
- Concurrent shared-generator stress is not yet run; sequential shared-state IO, pure rollback/monotonic transitions and actual MVar operations are qualified.
- Standalone String conversion, witness/extraction and immutable-unmarshal convenience wrappers are functionally covered but not individually timed.
- Structured error values preserve acceptance/refusal and receiver state; SDK error-message identity is not promised. Entropy OS failure handling inherits Effect.Random platform boundary.
- Packed parser optimization is design-only/unselected; observed canonical parse/render/generation gaps need further diagnosis.
- No exact per-window throttle delta: timing runner omitted pre-start cgroup telemetry; raw completion counters, all samples and variability are preserved.

04 / Reading the board

What earns a tick?

✓ VerifiedMatching code and required compiler role have passing evidence. Unchanged standalone runtime inputs are checked byte for byte.

! BlockedA known failure or an unmet implementation requirement. Failed evidence never receives a green tick.

◷ In progressImplementation or validation is underway. A running command earns no pass credit.

↻ Needs rerunEarlier results are preserved, but changed compiler inputs require new matching evidence.

□ PendingNo complete matching result yet. Coverage investigations remain explicit work.

This is the full recorded bootstrap scope, not a claim that every unknown compiler bug has already been discovered. The coverage audit must account for the remaining Rust-only targets before final sign-off.

## Contract

A genuine checked source producer may append `usage` to a defining nominal contract and retain that same complete contract as a public type header's optional `ownership`. Each usage row contains only the defining constructor identity, all ordinary fields and its exact result owner applied to the defining parameters. It has no tag, layout, body, callable ABI or source export. Absent optional keys preserve the previous canonical JSON exactly.

The initial field grammar contains compiler-owned scalars, own Type parameters, tuples, sealed `MVarCell`, and `Ref`/`Mut` with an own explicitly declared Region parameter. Constraints, erased/indexed/existential fields, callbacks, other nominal dependencies, refinements and opaque/codata declarations have no proof. Every constructor must be supported; no field or alternative may be omitted. Rust reads actual checked constructor parts; Native reads actual checked Core constructor schemes. Both producers cover all supported data families so proof presence does not depend on whether a constructor is public.

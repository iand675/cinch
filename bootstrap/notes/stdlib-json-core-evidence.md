# Source-backed JSON core checkpoint

This is a partial JSON package increment. `Text.Json.Value` provides owned source-backed values, exact validated numbers, independent raw-message snapshots, syntax validation, byte-preserving compact/indent/HTML transformations, quoting, original byte spans and a resumable lexer. Existing `Text.Json`, `Data.Json` and `Text.Codec` are unchanged. Typed descriptors and effectful stream adapters remain in progress; this checkpoint does not mark the full 92-record package complete.

The final module SHA-256 is `f52e7fe9d0ea33f455b7876484a8fa028f6fb32695c2a1d232b65a0625dc5793`. All 260 declarations, including private helpers and constructors, have canonical `-- |` comments; documentation extraction reports no diagnostics or orphans and no foreign-library framing in public library comments.

The independent reference is the pinned Go 1.27.4 SDK. Its internally enabled JSONv2 default selects seven `v2_*.go` files even when `GOEXPERIMENT` is empty. The active source hashes and default-experiment evidence are in `../evidence/stdlib/stdlib-json-active-reference.json`; the cumulative audit retains all 92 historical/shared and active facade records. The per-record capability plan remains explicit about partial number/raw/typed/effect capabilities.

The Native wrapper supplies no clang optimization flag: these are clang default O0 functional gates. Future timings will explicitly relink O2 rather than relabel these binaries.

The Unicode dependency is separately published at `fee3e98e`, cherry-picked here as `ba68b029`. Direct source dependencies are `Data.Array`, `Data.Bytes.Word`, `Data.Unicode.Kernel` and `Data.Unicode.Tables`; each validation receipt records their exact source hashes. Unicode print/space predicates make scalar diagnostic quoting precise, and the typed layer will use the same kernel's simple-fold matching.

The lexer retains at most six escape bytes or a bounded UTF-8 prefix. It preserves incomplete numeric punctuation checkpoints, token-start document checkpoints and leading-byte string checkpoints across chunks, including a final empty read. Grammar uses explicit container frames with a depth limit of 10,000. Documents take one owned input snapshot; navigation retains private spans and direct child indexes, and every exported byte buffer is a fresh copy. Raw messages distinguish absence from a present empty buffer.

The load-only inline LLVM classifier examines complete 16-byte intervals for whitespace, decimal digits, ordinary string bytes, ASCII quoting and HTML predicates. Owners remain live around raw traversals; scalar fringes are explicit. All writes and span copies use checked byte primitives. Assembly inspection confirms vector instructions and no RC/allocation in the private block traversal, but the generic mode still incurs per-block decisions and aggressive unrolling. Static-mode/fused traversal controls and public pipeline timings are a separate performance checkpoint; no JSON speedup claim is made here. The Rust target includes actual-kernel wasm32, AArch64 and big-endian PowerPC object checks, pending the parent's coordinated Cargo gate.

The first generated byte-list-heavy consumer overflowed the compiler host's original 8 MiB main stack before execution. The exact retained source builds successfully with an explicitly set 64 MiB compiler-host main stack in 24.55 seconds. Its deterministic source archive and identity receipt are `compiler/tests/fixtures/json-host-stack-original.tar.gz` and `../evidence/stdlib/stdlib-json-host-stack-diagnostic.json`. `RUST_MIN_STACK` controls spawned threads and is recorded separately. No compiled consumer's 8 MiB stack or ordinary 32 MiB heap was raised. Compact supported string literals reduce generated fixture syntax; source sharding is not claimed necessary.

General numeric string-cast forms, saturated/overflow numeric outcome values, typed/custom application conversions, record/map adapters, dynamic-number selection, and shared-state Decoder/Encoder behavior remain open. The independent generator already includes 79 typed observations and 270 token traces for those later gates, but they are not counted as passed by this core checkpoint. A validated-number factory intentionally rejects malformed JSON spellings; the explicit absent-spelling default is distinct from numeric zero and its checked conversions refuse the empty text.

<details class="doc-notes"><summary>Module notes</summary>

Choice-stream property testing and native-speed state-machine simulation
with automatic integrated shrinking (Hegel / Hypothesis / Hedgehog style).

Every `Gen a` is a pure function over a finite stream of bounded discrete
choices (`List Nat`). When a property or state-machine invariant fails, the
shrinker minimizes the underlying choice sequence directly—deleting slices
and binary-searching draws toward `0`—so nested data structures and failing
state-machine traces shrink automatically without writing `shrink` instances.

Use compile-time `machine` declarations for exhaustive small-scope checking
(with type-checked `symmetry`, static POR, `refines`, and manifest provenance),
and reuse the exact same pure action functions with `hegel-check-machine` for
fast native randomized simulation over large or unbounded state spaces.

</details>

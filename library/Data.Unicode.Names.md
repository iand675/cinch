<details class="doc-notes"><summary>Module notes</summary>

Exact immutable Unicode 17.0.0 named table catalogs and aliases.
Generated by tooling/generate_unicode_names.py. Original data provenance
and licensing are preserved beside tooling/data/unicode17-tables.json.
This String-facing catalog stays outside the numeric classification core.

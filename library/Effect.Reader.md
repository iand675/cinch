# Effect.Reader

Zero-overhead lexical reader capabilities (Read and TaggedRead), with ask, asks, local, and type-changing with-reader scoping that preserve purity.

<details class="doc-notes"><summary>Module notes</summary>

Effect.Reader: zero-overhead lexical reader capabilities.

A `Read a` capability is a first-class lexical capability supplied via
`with (r = Read val) in ...`, `run-reader val (\() -> ...)`, or
explicitly with `f @{r = Read val}`. Because it is a lexical value
(not an algebraic effect), functions taking `using (r :: Read a) =>`
remain pure (`->{}`), keep full LLVM pure-function attributes, and
compose directly with `parMap`, `STM`, and `Prop` proofs.

Multiple readers of distinct types coexist naturally; multiple readers
of the same payload type can be distinguished with `TaggedRead tag a`.
